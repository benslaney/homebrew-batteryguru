# Battery Guru — Homebrew Tap

A menu-bar battery monitor for macOS that shows live power draw (mA / watts),
charge state, and battery health — by [MacDaddy](https://macdaddy.io/mac-battery-guru/).

## Install

```sh
brew install --cask benslaney/batteryguru/battery-guru
```

Or tap first:

```sh
brew tap benslaney/batteryguru
brew install --cask battery-guru
```

Requires macOS 14 (Sonoma) or newer. The app is signed and notarized under
Developer ID *Ben Slaney*.
